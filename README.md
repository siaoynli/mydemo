# MyDemo - 登录页面

一个基于 Vue 3 + Naive UI 的单文件登录页面，无需构建工具，直接用浏览器打开即可。

## 在线预览

直接用浏览器打开对应静态文件，或使用任意静态服务器：

```bash
python3 -m http.server 8080
# 或
npx serve .
```

## 功能

- **验证码登录** — 手机号 + 验证码输入框（60秒倒计时）+ 密码输入框
- **二维码登录** — 手机扫码登录（占位）
- **密码显示切换** — 密码输入框右侧眼睛图标，点击切换明文/密文
- **暗黑模式切换** — 右上角太阳/月亮图标，一键切换明暗主题
- **语言切换** — 界面所有应编码的按钮，标题等等，都需要转换成可语言切换
- **第三方登录按钮** — 微信、QQ、GitHub（仅 UI）
- **表单校验** — 手机号格式校验（中国手机号）、空值校验
- **按钮防抖** — 登录和发送验证码按钮各自独立的 loading 状态，1.5秒内不可重复点击

## 技术栈

- **Vue 3** (CDN) — 组合式 API，`setup()` 语法
- **Naive UI 2.41.0** (CDN) — 通过 `app.component()` 手动注册组件
- **原生 CSS** — 内嵌 `<style>`，无预处理器
